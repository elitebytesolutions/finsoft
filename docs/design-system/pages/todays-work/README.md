## 1. Purpose

The operator's start-of-day screen: what is due today, what is overdue, and the shortest route to
clearing each item. It is a queue, not a report.

## 2. Anatomy

```
HeroBand (light, illustrated)   greeting · "Today's Tasks" · long date · progress ring
KpiRow (4 + ring)               Due today · Overdue · Completed · Scheduled this week · Daily progress
Grid  [ left rail 1fr ] [ centre 2fr ] [ right rail 1fr ]
  left    QuickActions (6 tiles) · Calculator
  centre  Generated/recent work strip · Today's Task List (tabs + table)
  right   Today's Agenda · Calendar · Upcoming Work · Tax Calculator
```

## 3. Components

`KpiRow` · `ProgressRing` (page-local, candidate for promotion) · `Tabs`
(All / Pending / In progress / Completed / Overdue) · `DataTable` · `Calendar` (month, dotted
day markers with a legend) · `AgendaList` · `QuickActions` · `Calculator` and `TaxCalculator`
(page-local utilities).

## 4. Data

Task list columns: `☐ · # · Task (+ subtitle) · Module · Priority · Due time · Status · Actions`.

| Column | Format |
|---|---|
| Task | 12px/700 with a 9.5px subtitle; module icon in a well |
| Module | Text chip — Banking, Sales, Inventory, Customers, Accounting |
| Priority | Badge: High `danger` · Medium `info` · Low `good` |
| Due time | `10:00 AM`, right-aligned |
| Status | Badge: Pending `warn` · In progress `info` · Completed `good` · Overdue `danger` |

Calendar legend tones: Tasks green · Meetings blue · Deadlines amber · Overdue red.

## 5. Actions

| Action | Kind | Permission | Confirm | Result |
|---|---|---|---|---|
| Add task | primary | any authenticated user | no | Creates a personal task |
| Complete (row checkbox) | inline | task owner | no | Marks complete; optimistic |
| Open (row click) | — | the target screen's permission | no | Routes to the screen that clears the task |
| Post (on a posting task) | — | the action's permission | **yes** | Never posts here — routes to the document |

Tasks generated by the system (cheques to post, stock to reorder, period to close) are **not
completable by hand** — they clear when the underlying condition clears, and the row says so.

## 6. States

- KPI counts must equal the rows behind them; a mismatch is a defect, not a rounding artefact.
- Empty: "Nothing is due today." with the next scheduled item named.
- The page refreshes on window focus and shows `Updated HH:MM`.

## 7. Financial rules on this page

Nothing posts here. A task that represents a posting action routes to the document entry or
approval screen, where the confirmation and permission checks live.

## 8. Responsive

`md` right rail moves below the centre column · `sm` left rail utilities collapse into an accordion ·
`xs` task list becomes a card list, calculators are hidden.

## 9. Accessibility

Task checkboxes are labelled with the task name. The progress ring has a text equivalent
("3 of 5 completed"). The calendar is a grid with `aria-selected` on the current day and arrow-key
navigation.

## 10. Deviations from the prototype

The prototype's "Generated by Me" strip of recent screens is a demo artefact and is replaced by
**Recently worked on** — the last documents this user opened or edited.
